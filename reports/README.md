# reports/

All substantial tasks must add/update a report in the corresponding area.

## Required report sections

- Task
- Branch
- Scope
- Approach
- Evidence / Sources
- Files Changed
- How to Run
- Evaluation
- Results
- Failures / Limitations
- Performance
- Comparison
- Recommendation (KEEP / REVISE / REJECT / NEEDS MORE EVALUATION)
- Reproducibility
- Next Steps

## Milestone 1 evaluation placeholders

Track (without fixed thresholds during bootstrap):
- total frames
- frames with left/right/both hands detected
- missing-frame percentage
- longest missing sequence
- handedness stability and identity swaps
- temporal jitter
- bone-length variation
- nonphysical coordinate jumps
- thumb reconstruction observations
- finger-crossing behavior
- hand-hand occlusion behavior
- runtime, effective FPS, peak GPU VRAM
